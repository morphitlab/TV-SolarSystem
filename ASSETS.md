# Planet Textures & Attribution

Procedural placeholder textures are bundled in `app/src/main/res/drawable-nodpi/` so the app builds and runs offline immediately.

## Swapping in Photorealistic 2K/4K Textures (One-Step Swap)
Replace the PNG files in `app/src/main/res/drawable-nodpi/` keeping the exact filenames below (mapped in `PlanetTextures.kt`):

| Filename | Recommended Source | License |
|---|---|---|
| `planet_sun.png` | Solar System Scope — 2k_sun.jpg (`https://www.solarsystemscope.com/textures/`) | CC BY 4.0 |
| `planet_mercury.png` | Solar System Scope — 2k_mercury.jpg | CC BY 4.0 |
| `planet_venus.png` | Solar System Scope — 2k_venus_atmosphere.jpg | CC BY 4.0 |
| `planet_earth.png` | NASA Blue Marble (`https://visibleearth.nasa.gov/`) or Solar System Scope | Public Domain / CC BY 4.0 |
| `planet_earth_night.png` | NASA Black Marble (`https://earthobservatory.nasa.gov/features/NightLights`) | Public Domain |
| `planet_moon.png` | NASA LRO Moon (`https://svs.gsfc.nasa.gov/4720`) | Public Domain |
| `planet_mars.png` | Solar System Scope — 2k_mars.jpg | CC BY 4.0 |
| `planet_jupiter.png` | Solar System Scope — 2k_jupiter.jpg | CC BY 4.0 |
| `planet_saturn.png` | Solar System Scope — 2k_saturn.jpg | CC BY 4.0 |
| `planet_uranus.png` | Solar System Scope — 2k_uranus.jpg | CC BY 4.0 |
| `planet_neptune.png` | Solar System Scope — 2k_neptune.jpg | CC BY 4.0 |

*Attribution:* If using Solar System Scope textures, retain credit to Solar System Scope (CC BY 4.0) in the app credits.
